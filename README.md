# Plastic Detection with YOLOv8

This repository contains a dataset and resources for detecting various plastic items using YOLOv8, aimed at plastic waste management.

## Dataset Details
The dataset has been annotated and exported in YOLO format. It is originally from Roboflow Universe (workspace `ranjan-s`).

It includes 6 classes of plastic waste:
- `plastic bag`
- `plastic bottle`
- `plastic container`
- `plastic cup`
- `plastic straw`
- `plastic utensil`

## Folder Structure
- `train/` : Training images and labels
- `valid/` : Validation images and labels
- `test/`  : Test images and labels
- `data.yaml` : YOLO dataset configuration file
